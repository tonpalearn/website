1
ภาพรวมโครงการ

Training AI Agentic แบบ แยกตามระดับผู้เรียน — แต่ละกลุ่มในองค์กรใช้ AI ต่างจุดประสงค์กัน ผู้บริหารต้องเห็นศักยภาพเพื่อตัดสินใจ พนักงานต้องใช้งานได้จริงทุกวัน และทีม IT ต้องสร้าง/ดูแลเครื่องมือเองได้ — ออกแบบให้ทุกกลุ่มเริ่มจาก ฐานความเข้าใจเดียวกัน ก่อนแยกไปตามความลึกที่ต้องใช้จริง

🎯 Pain Point
สอน AI แบบเดียวทั้งองค์กร → ผู้บริหารเบื่อเพราะง่ายไป พนักงานงงเพราะยากไป ไม่มีใครได้ของที่ใช้ได้จริงกับบทบาทตัวเอง
💡 แนวทาง
ฐานร่วม (Common) 4 ชม. ก่อนเสมอ → แยก 3 เส้นทางตามบทบาท: เข้าใจศักยภาพ (ผู้บริหาร) · ได้งานจริง (Staff) · สร้างเครื่องมือเอง (Developer)
⚙️ เครื่องมือหลัก
Claude Cowork (Setup + Connector + Skill) · Claude Code (Multi-agent + SDLC) — ไม่ต้อง code เป็นสำหรับ 3 กลุ่มแรก

โครงสร้าง 4 Class
Classระยะเวลาจำนวนคนต่อจาก
1 · Common
ภาพรวม AI + การใช้ Prompt ที่ถูกต้องเพื่อให้ได้งานที่ตรงความต้องการ + การทำให้ AI รู้จักเราจริงๆ
4 ชม.30 คนเริ่มต้น — ทุกคนจากกลุ่ม 2+3 เข้าร่วม
2 · Top Management
เข้าใจศักยภาพ และมี Mindset สำหรับ AI Agentic, Multi-agent, Brainstorm งานปัจจุบัน เพื่อหาจุดความเป็นไปได้ในการทำ AI Transformation
4 ชม.20 คนต่อจาก Class 1 (Common)
3 · Key Person / Staff
Workshop ลงมือใช้จริง สามารถใช้ Agentic ในการทำให้ได้งานจริง และมี Mindset สำหรับใช้งาน Agentic ทุกรูปแบบ
4 ชม.10 คนต่อจาก Class 1 (Common)
4 · Developer
Claude Code Technical + SDLC, มาตรฐานการพัฒนาระบบสำหรับองค์กรอย่างมืออาชีพ
4 ชม.10 คนแยกอิสระ — ไม่ต้องผ่าน Common

4 ชม. · 30 คน
Class 1 · Common — พื้นฐานการใช้ AI
Moduleเวลาเนื้อหา
1. AI คืออะไร45 นาทีภาพรวม AI ยุคปัจจุบัน · AI Agentic ต่างจาก AI Chat ทั่วไป (ChatGPT/Gemini) อย่างไร · เห็นภาพ End-to-End ว่า Agentic Workflow หน้าตาเป็นยังไง เพื่อปรับ Mindset AI
2. การใช้ Prompt ที่ถูกต้อง75 นาที
ทฤษฎี 30 + Workshop 45
หลักการเขียน Prompt ให้ได้งานตรงความต้องการ — Context / Instruction / Format ที่ชัดเจน · ตัวอย่าง Prompt ที่ใช้ได้ผลจริง เทียบกับ Prompt ที่มั่ว · Workshop: ฝึกเขียน Prompt จากงานจริงของตัวเอง จนได้ผลลัพธ์ที่ต้องการ
3. สร้าง User Preference ที่ดี75 นาที
ทฤษฎี 30 + Workshop 45
Agent File คือ "DNA" ของ AI ผู้ช่วย — ทำให้ AI รู้จักเราจริง ๆ · องค์ประกอบที่ต้องมี: Role / Context / Tone / Output Format · Workshop: เขียน User Preference ของตัวเองจากงานจริง
4. สรุป + Guardrail + Governance45 นาทีข้อพึงระวัง และมาตรฐานการทำงาน เมื่อจะใช้ AI ในองค์กร
🎁
Objective: เข้าใจการ คำว่า "AI" จริงๆ ว่า Agentic ต่างจากยุคก่อนยังไง และเรากำลังจะเจออะไรกันในยุค Agentic
4 ชม. · 20 คน
Class 2 · Top Management
Moduleเวลาเนื้อหา
1. Recap + มุมมองกลยุทธ์20 นาทีเชื่อมโยงจาก Common สู่การตัดสินใจระดับผู้บริหาร — จะใช้ AI ตรงไหนเพื่อสร้างมูลค่า ไม่ใช่แค่ประหยัดเวลา
2. Multi-agent Panel Review60 นาที
Demo สด
ให้ AI หลายมุมมองช่วยกลั่นกรองการตัดสินใจก่อนถึงมือผู้บริหาร · Demo สดด้วยโจทย์การตัดสินใจจริงขององค์กร
3. สร้าง Dashboard จากข้อมูลจริง60 นาที
Demo สด
ดึงข้อมูลจริงของบริษัท → ให้ AI วิเคราะห์ → ได้ Dashboard พร้อมใช้ภายในไม่กี่นาที (ไม่ต้องรอทีม IT)
4. กรณีศึกษา "Best Practice"40 นาทีเคสการใช้ AI ระดับผู้บริหารจากอุตสาหกรรมใกล้เคียง ปรับให้ตรงบริบทลูกค้า
5. Brainstorm + Q&A60 นาทีFacilitate ให้ผู้บริหารช่วยกันคิดและจัดลำดับว่าจุดไหนในองค์กรที่อยากเอา AI ไปใช้ก่อน
🎁
Objective: Roadmap แนวคิดการใช้ AI ระดับองค์กร (สรุปจาก Brainstorm) พร้อมลำดับความสำคัญ

Workshop

Workshop
